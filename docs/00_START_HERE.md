# 00 · 实物盘点、系统选型与上电安全（当前第一课）

## 学完这节的结果

你将有一份**可以检查、不靠记忆**的物料与接线档案，并能明确下一步走哪条分支。本节**无需接电源**，预计 30–60 分钟。

### 步骤 1：把零件放桌上，拍照并填表

**必须先断电、拔下电池与 USB-C。** 将机械装好的鸭子置于不易滚落、可稳定支撑的垫子上。
给每类板件拍**正、反面和插座特写**，包含丝印的型号和 Rev（可以遮挡订单号）。

| 部件 | 需要写下来的真实信息 | 为什么必须知道 |
|---|---|---|
| Radxa ZERO 3W | 内存/存储容量、有无焊 40 针、microSD 容量 | 选系统镜像、排查启动 |
| HD1910 | 型号完整后缀、每只贴纸编号、实际数量、线缆接口 | 防止混入不同电压/协议型号 |
| HAT | 官方 RPI Robot HAT？kissqy/其他版本？PCB 版本？是否已贴片？ | 供电、3P 舵机插座、半双工驱动**不能想当然** |
| IMU | `imu_to_dxl` 自制板/飞特固件？BNO085 I²C？其他？有无烧录？ | 不同软硬件路径**不能直接混用** |
| 供电 | 2S 电池/稳压电源型号、接口、保护板/保险丝、输出额定 | 主板 5V 与舵机供电必须分开 |
| 调试器 | 飞特 FE-URT-1/-2 或等价 USB 半双工适配器，供电能力/端子照片 | 单舵机配置通常需独立调试路径 |
| 工具 | 可测电压/通断的万用表、绝缘工具、限流电源（推荐）、支架 | 缺少基本检查工具时停止实机通电 |

使用 [S0–S2 自动准备与现场验收卡](06_S0_S2_AUTOMATION.md) 复制 15 个标签的空白台账；未知型号、引脚、供电与关节映射一律记 `BLOCKED`。按 H0 的六项要求提交盘点和断电测量证据。

建立一个不入库的个人设备记录（可参考 `records/TEMPLATE.md`，照片和测量摘要可按需入库，敏感信息不要提交）。

### 步骤 2：画电源拓扑，千万不要把 2S 接到主板

```text
          2S 电池/台式电源（负极共地，前提是设计允许）
                    |
             熔断保护 + 总电源开关
                    |
          +---------+-----------+
          |                     |
     舵机电源母线         HAT/独立 DC-DC 稳压
    HD1910（按铭牌）       经过实测的 5V 输出
          |                     |
     15 个串行舵机         Radxa ZERO 3W
        + 总线 DATA          （不得直接接 2S）
```

上图仅用于**理解两条电源路径**，**不是实物接线图**：电源正负脚、哪个接口能输出 5V、GPIO 是否受电必须由你手头 HAT 原理图/丝印/万用表共同核对。

Radxa 官方要求 USB-C 输入**5V**，建议至少 5V/2A；严禁给主板 USB-C 直接输入 7.4/8.4V。2S 锂电满电可达 8.4V；HD1910 电压必须结合**准确型号数据手册**确定，不能用 XL330 的供电要求替代。不要带电插拔线缆。首次调试用可调、有限流/可读取电压电流的实验电源更易排错；电流上限应按所接阶段的负载和线材安全额定设定，**不要笼统“调到最大”**。

### 步骤 3：识别你的 HAT + IMU 软件路线

| 实物组合 | 可研究的软件基线 | 仍需确认 |
|---|---|---|
| 官方 HAT + 原 `imu_to_dxl` | 官方 Pollen Rust 运行时是 **Dynamixel/XL330** 的原始路径 | HD1910 **飞特协议总线适配**、IMU 固件的协议/读数是否匹配 |
| kissqy HAT + kissqy 飞特总线 IMU | kissqy 公开了 HD1910 固件及 ZERO 3W 整合镜像 | HAT/IMU **Rev 与固件**、接口线序、镜像适配范围 |
| 官方/自制 HAT + BNO085 等 I²C IMU | fanhao375 有 I²C IMU 移植与实机实验记录 | 需复用其对应 runtime 补丁；**kissqy 默认镜像不能直接假设兼容 BNO085** |
| 仅降压模块 + 半双工转接板，无 HAT | fanhao375 有不打 HAT 的方案 | 原作者将其作为**未完整实机验证**的方案；GPIO 电平/5V/控制台 UART 必须核查 |

社区的资料中三针的 **Signal/GND 脚序曾出现互相矛盾的文字**，而不同型号、插座正反朝向和线束端视图会改变编号理解。最终只采用**手中具体型号、从端子正面标注的方向和断电通断测量**。不要按线色或“飞特和 Dynamixel 一样”来接电源。

### 步骤 4：四个“禁止越过”的门槛

1. **没有 HAT 版本对应的原理图/Pinout、尚未量好正负极** → 不接电池、不叠接 HAT 到 Radxa。
2. **没有单舵机只读扫描/确认同一总线协议** → 不做整机批量写 ID/参数。
3. **没有 IMU 正负轴、静止偏置和总线时序验证** → 不启用 Policy。
4. **没有可触达断电开关、支撑架和关节方向检查** → 不让全部舵机上力。

### 步骤 5：交付这节的证据

填到你的实验记录中：日期、完整型号/PCB 版次、HAT/IMU 照片、模块规格书链接、电源拓扑（标 GND/+BATT/+5V/DATA）、单板 USB-C 电源适配器铭牌、未知引脚列表。**完成后进入 [01 · 主板单独启动](01_BOARD_BOOT.md)，仍然不接舵机。**
