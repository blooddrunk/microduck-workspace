1. 实物 PCB/芯片型号、VCC 允许范围、DATA/VCC/GND 实际引脚、卖家协议 v1.2 与固件身份
2. 确认供电安全后才单独台架只读 1Mbps、ID200 地址 0 长 5 身份、56 长 15 数据、错误率/状态位
3. 核对 `raw/16.4` °/s 和 kissqy `0.0175°/LSB` 的差异、四元数、姿态坐标及新鲜度
