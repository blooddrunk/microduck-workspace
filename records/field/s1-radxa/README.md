1. microSD 镜像下载来源/完整 hash、镜像或 U-Boot 的固定版本；刷卡前备份/刷卡后核对
2. 主板脱离 HAT、舵机、IMU、电池，用已确认 5V 单路 USB-C 启动；登录 SSH 和安全关机证据
